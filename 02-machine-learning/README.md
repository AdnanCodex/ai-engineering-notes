# Machine Learning

My hands-on Machine Learning notes — from data preprocessing to regression, classification, ensemble methods and unsupervised learning, practised dataset-wise with scikit-learn.

> **Note:** This page is a public showcase of what this section covers. The full notebooks (complete code, outputs and datasets) are maintained in a **private repository** to protect the original work. If you are a teacher or recruiter and need access, feel free to contact me.
