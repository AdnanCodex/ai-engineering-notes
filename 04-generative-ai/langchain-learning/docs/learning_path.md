# Learning Path

Follow the topic folders in order. Each one builds on the previous.

| Stage | Notebooks | You will be able to |
|-------|-----------|---------------------|
| 1. Foundations | 01 Models, 02 Prompts | Call chat/embedding models and build reusable prompts |
| 2. Controlling output | 03 Structured output, 04 Output parsers | Get typed, validated results |
| 3. Composition | 05 Chains, 06 Runnables | Build pipelines with `\|` |
| 4. Data pipeline | 07 Loaders, 08 Splitters | Ingest and chunk documents |
| 5. Retrieval | 09 Vector stores, 10 Retrievers, 11 RAG | Answer questions over your own data |
| 6. Autonomy | 12 Tools, 13 Agents | Let the LLM call tools to complete tasks |

## Suggested next topics
- LangGraph for stateful, multi-step agents
- Conversation memory
- Evaluation with LangSmith
- Persistent RAG over PDFs with Chroma
